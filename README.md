# css-stacked-card-layout
A modern stacked card layout project built using HTML and CSS. 
This project demonstrates absolute positioning, z-index stacking, hover scaling effects, shadows, and responsive card styling.

## Description

This project demonstrates how to create a visually appealing stacked card interface using fundamental CSS concepts.

The cards are layered using `position: absolute` and `z-index`, creating an overlapping effect while maintaining proper spacing and alignment.

Each card contains:

* Unique background colors
* Rounded corners
* Shadow effects
* Hover animations
* Responsive positioning

The project helps students practice layout structuring, positioning, stacking order, transitions, and interactive UI effects.
